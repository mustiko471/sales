# Sumber konten dan aset

Diperiksa pada 6 Oktober 2026. Gambar kendaraan diambil dari katalog publik Toyota-Astra Motor untuk preview pengembangan lokal. Hak merek dan materi tetap pada pemiliknya; tersedianya file publik bukan bukti lisensi penggunaan komersial. Pemilik website perlu menyediakan materi dealer yang diizinkan atau mengonfirmasi penggunaan aset sebelum publikasi.
